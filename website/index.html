Point at the problem.Your agent finds the code.

Pinpoint is a free Chrome extension for giving UI feedback to AI coding agents. Click anything on a page, say what's wrong, and copy notes your agent can act on: the selector, component, source file and styles.

What your agent gets

          

        

      

    

  


  

    

      
Details that save a round trip

      

        
Pause animations
Freeze CSS, video and JavaScript animations to annotate the exact frame.

        
Quote any text
Select a typo or a sentence and it's quoted in your note.

        
Saved per page
Markers stay put until you clear them, even after a reload.

        
Choose the detail
Compact, standard or full: from just the selector up to computed styles.

        
Inside web components
Selectors reach into open shadow roots with >>>.

        
Keyboard friendly
Alt+Shift+A to start, Esc to stop, Cmd+Enter to add a note.

      

    

  


  

    

      
Install in under a minute

      

        

          
    
            
  1. Download the code from GitHub
    2. 
            
  2. Open chrome://extensions and turn on Developer mode
    3. 
            
  3. Click Load unpacked and choose the pinpoint folder
    4. 
            
  4. Click the Pinpoint icon on any page
    5.
